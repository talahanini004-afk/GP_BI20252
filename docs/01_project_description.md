# Business Intelligence Project Description and Objectives

## Project Description

This project is a Business Intelligence and data analytics project that focuses on analyzing unemployment in Jordan and identifying its socioeconomic determinants during the period 2014–2024.

The project belongs to the economic and labor market analysis domain. It uses data-driven methods to support decision-making and improve understanding of labor market challenges across Jordanian governorates.

The project uses a panel dataset that includes governorate-level observations across multiple years. The main dependent variable is the unemployment rate, while the explanatory variables include population density, establishments per 1,000 people aged 15 and above, schools per 1,000 population, students per class, and student ratio for the 5–19 age group.

## Objectives

- Analyze unemployment trends in Jordan from 2014 to 2024.
- Identify socioeconomic factors related to unemployment.
- Apply panel data regression models.
- Compare Pooled OLS and Fixed Effects regression.
- Evaluate model performance using R², RMSE, MAE, residual plots, and LOYO validation.
- Apply VIF to check multicollinearity.
- Apply PCA and clustering techniques.
- Build Tableau dashboards for visualization and decision support.

## Business Questions

- How has unemployment changed in Jordan between 2014 and 2024?
- Which governorates show higher or lower unemployment rates?
- What socioeconomic indicators are associated with unemployment?
- Can governorates be grouped based on socioeconomic similarity?
- Which model performs better: Pooled OLS or Fixed Effects?
- Can dashboards help decision-makers understand unemployment patterns?
