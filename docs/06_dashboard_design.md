# Dashboard Design and Business Insights

## Dashboard Overview

Two Tableau dashboards were created in this project:

1. Labor Market Overview Dashboard.
2. Key Factors Affecting Unemployment Dashboard.

The dashboards were designed to answer two different but connected analytical questions:

- Dashboard 1 answers: What is happening?
- Dashboard 2 answers: Why is it happening?

## Dashboard 1: Labor Market Overview

The first dashboard provides a general understanding of unemployment patterns in Jordan between 2014 and 2024.

It includes:

- Unemployment trend over time.
- Governorate-level unemployment comparison.
- Geographic visualization using a map.
- Employment and unemployment profile comparison.
- Interactive filters for year and governorate.

## Dashboard 1 Business Question

This dashboard answers:

**What is happening in Jordan’s labor market?**

## Dashboard 1 Insight

The Labor Market Overview dashboard showed that unemployment is not distributed equally across governorates. Some governorates show higher unemployment levels than others, and unemployment also changes over time.

The dashboard also showed that unemployment increased noticeably after 2016 and reached a peak around 2021.

## Dashboard 2: Key Factors Affecting Unemployment

The second dashboard focuses on possible explanations behind unemployment patterns.

It includes visual relationships between unemployment and selected socioeconomic indicators:

- Establishments per 1,000 people aged 15 and above.
- Population Density.
- Schools per 1,000 population.
- Regression coefficient visualization.

## Dashboard 2 Business Question

This dashboard answers:

**Why is unemployment happening?**

## Dashboard 2 Insight

The dashboard showed that unemployment is connected to a combination of economic, demographic, and educational indicators.

The establishments indicator represents economic activity and potential job creation. Population density represents demographic pressure. Schools per 1,000 population represents educational infrastructure.

## Dashboard Design Principles

The dashboards were designed using Business Intelligence principles:

- Clear dashboard titles.
- Interactive filters.
- Visual hierarchy.
- Readable charts.
- Consistent visual style.
- Analytical storytelling.
- Decision-support focus.

## Dashboard Summary

Together, the dashboards create a complete Business Intelligence story. The first dashboard helps users understand the unemployment problem visually, while the second dashboard helps users explore socioeconomic indicators that may explain the problem.
