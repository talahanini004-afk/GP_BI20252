# Tools Research and Selection Effort

## Introduction

Several tools were used in this project to support data organization, cleaning, statistical modeling, machine learning, visualization, documentation, and project sharing.

## Tools Used

| Tool | Purpose |
|---|---|
| Excel | Data organization and derived calculations |
| Python | Cleaning, modeling, validation, clustering, and output generation |
| Pandas | Data manipulation |
| NumPy | Numerical calculations |
| Statsmodels | Regression modeling and diagnostics |
| Scikit-learn | PCA, clustering, scaling, and evaluation metrics |
| Matplotlib | Figure generation |
| SciPy | Hierarchical clustering and dendrogram |
| OpenPyXL | Reading and writing Excel files |
| Tableau | Interactive dashboard development |
| GitHub | Project documentation and version control |

## Why These Tools Were Selected

Excel was selected because it is useful for organizing structured data and reviewing calculations visually.

Python was selected because it provides strong libraries for data science, statistical modeling, machine learning, and visualization.

Statsmodels was used because it provides detailed regression outputs such as coefficients, p-values, standard errors, and robust standard errors.

Scikit-learn was used for standardization, PCA, K-Means clustering, Silhouette Score, and evaluation metrics.

Tableau was selected because it provides strong Business Intelligence visualization capabilities and interactive dashboards.

GitHub was used to organize the project files, document the methodology, and make the project easier to share and reproduce.

## Tools Summary

The selected tools supported the full Business Intelligence workflow from data preparation to modeling, visualization, documentation, and final delivery.
